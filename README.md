# ToxiTrack-AI 🚀

![Dashboard Screenshot](dashboard.png)

### AI Powered Toxicity & Behavior Analysis Platform

ToxiT-WebApp is a smart web application designed to analyze text conversations and detect toxic behavior in real time. It identifies abusive language, threats, harassment, emotional tone, intent, and escalation patterns using an intelligent hybrid AI approach.

Built for online communities, gaming chats, workplaces, and social platforms where healthy communication matters.

Repository Name: ToxiT-WebApp

---
## 🌟 Problem We Solved

Online chats often become toxic before moderators notice. Most tools only detect obvious abusive words and miss:

- Mild negativity  
- Passive aggression  
- Formal harassment  
- Threatening intent  
- Conversation escalation  
- Hinglish / mixed language toxicity  

ToxiT-WebApp solves this by going beyond keywords and analyzing behavior patterns.

## 🧠 How It Works

The system uses a multi-layer engine that checks:

1. Toxic phrases  
2. Context awareness  
3. Emotion signals  
4. User intent  
5. Threat patterns  
6. Conversation health  
7. Escalation forecasting  

This creates smarter results than basic bad-word filters.
